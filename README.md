# КУРСОВАЯ РАБОТА №3: Приложение для поиска вакансий на сайте HH.ru с загрузкой их в базу данных

## Данный проект является парсером по сайту HH.ru.
### 1. Класс API
### 2. Класс для работы с вакансиями
### 3. Класс для работы с компаниями
### 4. Клас для работы с базой данных
### 5. Вспомогательные функции
### 6. Функция взаимодействия с пользователем

# **Установка**:

### Для работы приложения необходимо установить интерпретатор *poetry*:

```pip install --user poetry```

### Так же клонируйте репозиторий:

```git clone https://github.com/Konstantin-Voronin-23/Project1.git```


# **Установка зависимостей**:

### Для работы проекта воспользуйтесь командами для установок зависимостей:

```
poetry add --group lint flake8
poetry add --group lint mypy
poetry add --group lint black
poetry add --group lint isort

poetry add --group dev pytest
poetry add --group dev pytest-cov
poetry add python-dotenv
poetry add requests
poetry add pandas
poetry add openpyxl
pip install psycopg2

```


# **Реализация модулей**:

## 1. Модуль hh_api для получения вакансий с HH.ru в нем реальзовано:

<details>
<summary><b>❗ ФУНКЦИИ ❗</b></summary>

### - Метод _connect :
    - Проверка доступности API вакансий
### - Метод get_vacancies :
    - Получает список вакансий по ключевому слову
### - Метод get_employers :
    - Поиск работодателей по тексту

</details>

## 2. Модуль vacancy для работы с вакансиями в нем реализовано:

<details>
<summary><b>❗ ФУНКЦИИ ❗</b></summary>

### - Метод get_salary_average :
    - Возвращает среднее значение зарплаты или None, если зарплата не указана
### - Метод from_api_data :
    - Создаёт объект Vacancy из данных, полученных из API

</details>

## 3. Модуль company для работы с компаниями в нем реализовано:

<details>
<summary><b>❗ ФУНКЦИИ ❗</b></summary>

### - Метод to_db_tuple :
    - Возвращает данные компании в виде кортежа для вставки в базу данных
### - Метод from_api_data :
    - Создаёт объект Company из данных, полученных из API

</details>

## 4. Модуль db_manager для работы с базой данных в нем рееализовано:

<details>
<summary><b>❗ ФУНКЦИИ ❗</b></summary>

### - Метод connect :
    - Устанавливает соединение с БД, если оно ещё не установлено
### - Метод close :
    - Закрывает соединение с базой данных, если оно открыто
### - Метод create_tables :
    - Создаёт таблицы компаний и вакансий, если они ещё не существуют
### - Метод insert_company :
    - Вставляет компанию в таблицу companies
### - Метод insert_vacancy :
    - Вставляет вакансию в таблицу vacancies
### - Метод get_companies_and_vacancies_count :
    - Возвращает список компаний и количества вакансий у каждой компании
### - Метод get_all_vacancies :
    - Возвращает список всех вакансий с деталями понятными для пользователя словами
### - Метод get_avg_salary :
    - Возвращает среднюю зарплату по всем вакансиям
### - Метод get_vacancies_with_higher_salary :
    - Возвращает список вакансий с зарплатой выше средней
### - Метод get_vacancies_with_keyword :
    - Возвращает список вакансий, в названии которых содержится переданное слово

</details>

## 5. Модуль utils для вспомогательных функций в нем реализовано:

<details>
<summary><b>❗ ФУНКЦИИ ❗</b></summary>

### - Метод create_database :
    - Создаёт базу данных, если она ещё не существует
### - Метод fill_database_with_api_data :
    - Запрашивает у пользователя ключевое слово для поиска, загружает компании и вакансии из API HeadHunter,
    и добавляет их в базу данных
### - Метод setup_and_fill_database :
    - Полная инициализация базы: создание, создание таблиц, заполнение данными

</details>
